# Credit Controls Demo

A clickable clinic-portal demo of credit controls. It shows paused exams, the "problem with your card" screen, and a Billing page with 10 charges per page and a date-range export. Switch scenarios from the bottom bar.

Open the live page, or open `index.html` locally. It needs no install.

All data is made up. The card form only takes demo cards, and nothing is sent anywhere.
